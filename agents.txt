## The one rule that decides everything
EVERY print needs a Binance Agentic ID held by the printing wallet — free or paid.
The contract checks the Agent ID registry (0x60B9262456dE011F7d15a54CdD8c48bAaa8B022F, balanceOf(user) > 0) on-chain and REVERTS without one. There is no any-wallet paid lane. Always check the ID first; if the wallet holds none, stop and report "NO AGENT ID" — do not send a transaction that will revert.

## What a print pays (Stage I — the current stage)
- Free print (first print per wallet): 20,000,000 $TALVIO, 0 BNB — gas only.
- Paid print: 100,000,000 $TALVIO for 0.002 BNB — a paid print pays 5x the free print.
- Later stages pay less per print (paid 90M / 80M / 70M / 60M, free always 20% of paid). 5 stages x 2,000 prints = the 10,000-print first issue; the trading pool opens automatically at print #10,000.
- Max 10 prints per wallet, ever (1 free + up to 9 paid = 0.018 BNB for all 9 at any stage).

## Contract calls
- Chain: BNB Smart Chain (56).
- TalvioPrint: 0xC433c77ACF8e5724e690DCbcf4c820Ed63FFd533
- $TALVIO token: 0xD16a3Ce432c7256F8837E81aF2007C16Ac4E7C4D
- Binance Agent ID registry: 0x60B9262456dE011F7d15a54CdD8c48bAaa8B022F (every print requires balanceOf(user) > 0).
- quotePrint(uint256 qty, address user) -> (cost, tokens): the authoritative price and payout for that wallet. Its cost already reflects the free print if one is still available. Always quote first and send exactly that cost as the transaction value.
- print(uint256 qty, address referrer): first print per wallet is free (quote cost 0); further prints 0.002 BNB each; max 10 per wallet; excess BNB is refunded.
- totalPrints() / currentJackpotRound() / currentTop3(): live progress and the current round's leaders.
- roundWinners(uint256 round) / jackpotPrize(uint256 round, address user): who won a finished round and what a wallet can claim.
- claimJackpot(uint256 round): winners claim their round prize (600M / 360M / 240M $TALVIO); value 0 BNB, no expiry.
- PancakeSwap V2 router: 0x10ED43C718714eb63d5aA57B78B54704E256024E.
- Never print more than the user asked for. Never deploy contracts or move funds without explicit user confirmation.
